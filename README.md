# Terlik Balistik Laboratuvari

> Ev icinde firlatilan bir terligin yorunge, menzil ve toplumsal utanc degerlerini
> ISO-benzeri ciddiyetle hesaplayan bagimsiz arastirma yazilimi.

Bu depo, salonun 4.5 metrelik koridorunu bir balistik tuzel olarak kabul eder.
Newton da terlik giyerdi; kaynak belirtilmemistir cunku kaynak evdeki herkestir.

## Kurulum

```bash
python3 terlik.py
python3 terlik.py 8 42 5.0 3
```

Parametreler: ofke (1-10), firlatma acisi (derece), hedef mesafe (metre), tanik sayisi.

## Bilimsel varsayimlar

- Yercekimi 9.81 m/s^2, balkon dahil.
- Terlik kutlesi 280 gram. Ponponlu modeller desteklenmez.
- Hava direnci ihmal edilir cunku evde ruzgar yok sanilir.
- Isabet basari sayilmaz; utanc katsayisi asil ciktilardir.

aci ile tartisilir. Bu yazi ciddi durur. Durmasi gerekir. Icerisi komiktir.
